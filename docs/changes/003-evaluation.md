## 改前、改後與驗證

原本缺標會警告後算 0；現在停止正式計分並列出待補數量／ID。原 Hark FINAL 不會轉名為人工結果；新模板不填任何 0/1。固定分母 5、空位算 0、不完整標註停止、同人雙檔拒絕、分歧需仲裁、query/run hash 變動拒絕，均列入最終驗證。

新的每題暖機與 timing 邊界已寫明；不把只量後端的毫秒數當作瀏覽器操作延遲。工具可驗欄位與人員自我聲明，不能認證真實身分。
