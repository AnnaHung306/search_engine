## 根因與改動

- **GTFOBins sudo**：相關文件已在索引。BM25 把 `gtfobin` 當詞彙，其餘詞的部分匹配可把別站推到前面。原首筆 unhide 得 9.57，其中 `technique` 貢獻 5.50；第一筆 GTFOBins 為第 6。新 `query_intent.py` 只辨識明確來源，將 URL host 是否相符作排序依據，同層保持 BM25。沒有把同站直接算作相關。
- **native libraries**：Frida JavaScript API 在索引內，第 23 名。文件用 `Process.enumerateModules()` 描述已載入模組；單加一般 `module` 仍只到第 13。新規則要求已載入、列舉、原生／程序及模組／函式庫語境，補入精確 API token（0.5），並優先排有該 token 的候選。核心模組、匯出符號、載入新函式庫及否定語境等不觸發。
- 兩個訊號可分開比較；`search.py --bm25 --intent` 同時開啟。沒有重爬、改索引、改舊 BM25 公式、改網站或換必做預設。非匹配候選留在同次排序的低層，沒有改用另一搜尋流程或新增應用 fallback。
- 共用前五筆匯出及全文判定準備；新 `intent_evaluation.py` 使用凍結計畫，與舊評估計分路徑分隔。審查修正否定語境、兩版計分器可能指錯目錄、manifest／plan 設定必須一致、判定需覆蓋每個配對的所有分段。修改守門後逐列重現 360 筆凍結排名／分數。
